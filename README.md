# Исследование и разработка алгоритма фильтрации электрокардиограммы от миографических шумов

В данном репозитории представлены 2 метода для фильтрации сигнала ЭКГ, оформленные в виде модулей. Для запуска потребуется склонировать этот репозиторий, а также файл ЭКГ в формате.edf.

## Запуск

```
python3 -m IRM -f file.edf # запуск фильрации с помощью метода IRM
python3 -m DB8 -f file.edf # запуск фильрации с помощью метода DB-8
``` 
После флага -f или --file необходимо указать путь до файла для обработки.
